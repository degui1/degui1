## About

Hi, welcome.

I'm Guilherme Gonçalves, a Full-Stack Software Engineer with 3+ years of experience working with React, TypeScript, JavaScript and Node.js.

My work is focused on enterprise system modernization, scalable frontend architecture, performance optimization, real-time dashboards, REST APIs, WebSockets and backend automation with NestJS.

Here you will find projects, experiments and studies related to web development, architecture, automation and AI-assisted development tools.
